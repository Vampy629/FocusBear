## 3. Focus Bear Tracking & Verification Protocol

1. **Explicit Session Tagging:** Each block starts with a named focus session matching the day’s work ticket (e.g., `Focus: Issue #204 - API Sync`).
2. **Scheduled Block Enforcement:** Distraction-blocking modes remain active during 09:00–13:00 and 14:00–17:30 windows.
3. **Weekly Verification:** Every Friday by 18:00, Focus Bear focus hour summaries are exported to demonstrate the completion of the 15-hour weekly requirement.
